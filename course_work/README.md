# Умножение матриц с OpenMP и MPI

Курсовая работа по дисциплине «Архитектура суперкомпьютеров». Один исходный файл C++17 используется для четырёх вариантов умножения плотных целочисленных матриц.

- `build/matmul-seq` — последовательный режим, 1 узел и 1 поток.
- `build/matmul-omp` — OpenMP, 1 узел и 4 потока.
- `build/matmul-mpi` — MPI, 2 узла с одним однопоточным рангом на каждом.
- `build/matmul-hybrid` — MPI + OpenMP, 2 узла с одним рангом и двумя потоками на каждом.

## Воспроизведение

Все команды выполняются из `course_work`. Для повторения замеров на одном компьютере нужен запущенный Docker с доступными виртуальными CPU 0–3. Сценарий строит образ Ubuntu и запускает два контейнера с отдельными сетевыми пространствами. Каждый замер сравнивает полученную матрицу с последовательным эталоном. После успешной серии сценарий обновляет CSV и журнал в `results/`.

```sh
bash bench/docker/run.sh
```

Чтобы собрать четыре бинарника на Ubuntu, нужны `g++`, `make`, `libopenmpi-dev` и `openmpi-bin`. На втором узле нужны совместимые версии `openmpi-bin` и `libgomp1`. Для запусков по SSH настройте Open MPI между двумя узлами и разместите каталог `build` по одинаковому абсолютному пути. Сборка и запуск на первом узле:

```sh
make
bash bench/run.sh --host node-a:1,node-b:1
```

Программы принимают размер квадратной матрицы и число измерений после одного прогрева. Эталон хранится как последовательность `int32_t` в порядке строк и в нативном порядке байтов. Пример локального запуска с точной сверкой:

```sh
./build/matmul-seq 257 7 --write-reference build/reference.bin
OMP_NUM_THREADS=4 ./build/matmul-omp 257 7 --read-reference build/reference.bin
```

Для сборки PDF нужны Python 3, XeLaTeX, `latexmk` и пакеты TeX Live с кириллицей и PGFPlots. `make report` проверяет CSV и журнал, пересчитывает статистику и собирает PDF. Текст обсуждения описывает сохранённую серию измерений. Проверка стиля C++ выполняется через `make lint` с `clang-format`.
